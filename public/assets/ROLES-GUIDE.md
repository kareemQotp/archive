## دوال النظام المتاحة:

### دوال أساسية:
- `getRoleInfo(roleKey)` - الحصول على معلومات الدور
- `hasPermission(userRole, permission)` - التحقق من الصلاحية
- `hasFeature(userRole, feature)` - التحقق من الميزة
- `getAllRoles()` - الحصول على جميع الأدوار مرتبة

### دوال متقدمة:
- `getRolesByPermission(permission)` - الأدوار حسب الصلاحية
- `getRolesByFeature(feature)` - الأدوار حسب الميزة
- `getAllPermissions()` - جميع الصلاحيات
- `getAllFeatures()` - جميع الميزات
- `isValidRole(roleKey)` - التحقق من صحة الدور
- `compareRolePriority(roleA, roleB)` - مقارنة أولوية الأدوار
- `getRoleColor(roleKey)` - لون الدور
- `getRoleIcon(roleKey)` - أيقونة الدور

## أمثلة الاستخدام:

```javascript
// التحقق من الصلاحية
if (hasPermission('admin', 'manage_users')) {
    // السماح بإدارة المستخدمين
}

// الحصول على جميع الأدوار التي تملك صلاحية معينة
const rolesWithUpload = getRolesByPermission('upload_documents');

// الحصول على معلومات دور معين
const adminInfo = getRoleInfo('admin');
console.log(adminInfo.name); // "مدير النظام"
console.log(adminInfo.color); // "#dc3545"

// التحقق من ميزة
if (hasFeature('legal', 'contracts')) {
    // إظهار قسم العقود
}
```

## تطبيق النظام:

1. **عند تسجيل الدخول:** حفظ دور المستخدم في session
2. **في القائمة الجانبية:** عرض الميزات حسب الدور
3. **في الصفحات:** التحقق من الصلاحيات قبل العرض
4. **في العمليات:** التحقق من الصلاحيات قبل التنفيذ
