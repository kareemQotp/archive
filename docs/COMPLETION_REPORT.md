## 🚀 طريقة التشغيل

### 1. إصلاح النظام (مطلوب مرة واحدة):
```bash
npm run fix:notifications
npm run setup:departments  
npm run update:users
```

### 2. تشغيل النظام:
```bash
npm start
```

### 3. اختبار النظام:
1. افتح http://localhost:5000
2. سجل دخول بمستخدم من إدارة معينة
3. تحقق من التوجيه التلقائي
4. اختبر الإشعارات
