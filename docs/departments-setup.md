# إعداد النظام الهجين للإدارات

## تشغيل إعداد الإدارات

1. تأكد من تثبيت Node.js
2. قم بتثبيت Firebase Admin SDK:
```bash
npm install firebase-admin
```

3. تشغيل إعداد الإدارات:
```bash
cd scripts
node setup_departments.js
```

## طرق التسجيل:

### 1. التسجيل عبر اختيار الإدارة
- المستخدم يختار الإدارة التابع لها
- يتم إرسال الطلب لمدير الإدارة للموافقة

### 2. التسجيل عبر كود الدعوة
- مدير الإدارة يرسل دعوة للموظف
- الموظف يستخدم كود الدعوة للتسجيل
- إمكانية الموافقة التلقائية

## الصفحات الجديدة:

1. **register.html** - محدثة لتدعم النظام الهجين
2. **invitations.html** - إدارة الدعوات لمدراء الإدارات
3. **user-management.html** - محدثة لتدعم فلترة الإدارات

## الخطوات التالية:

1. **إنشاء مدراء الإدارات**: إنشاء حسابات مدراء الإدارات الأولى
2. **تخصيص الأدوار**: تحديد الأدوار المناسبة لكل إدارة  
3. **إعداد الإشعارات**: نظام إشعارات للمدراء عند طلبات الانضمام
4. **التقارير**: تقارير مفصلة لكل إدارة

## ملاحظات هامة:

- المدير العام (`admin`) يرى جميع المستخدمين والإدارات
- مدراء الإدارات يرون مستخدمي إدارتهم فقط
- يمكن للمستخدمين التسجيل بطريقتين (اختيار الإدارة أو كود الدعوة)
- نظام الدعوات يدعم انتهاء الصلاحية والتمديد
