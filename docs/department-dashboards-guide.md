# نظام لوحات التحكم المنفصلة للإدارات

## نظرة عامة

تم إنشاء نظام لوحات تحكم منفصلة لكل إدارة مع توجيه تلقائي للمستخدمين حسب إداراتهم.

## الإدارات المنشأة

### 1. إدارة الأرشيف العام
- **الصفحة**: `archive-dashboard.html`
- **اللون**: أخضر (#2E8B57)
- **الوظائف**: إدارة الوثائق، التصنيف، البحث في الأرشيف
- **الإحصائيات**: عدد الوثائق، الملفات المصنفة، رفع هذا الشهر، عمليات البحث

### 2. إدارة الشؤون القانونية  
- **الصفحة**: `legal-dashboard.html`
- **اللون**: ذهبي (#B8860B)
- **الوظائف**: العقود، القضايا، الاستشارات القانونية
- **الإحصائيات**: العقود النشطة، القضايا الجارية، الاستشارات، المواعيد المقبلة

### 3. إدارة التحصيل
- **الصفحة**: `collection-dashboard.html`  
- **اللون**: أحمر (#DC143C)
- **الوظائف**: إدارة الديون، تتبع المدفوعات، خطط السداد
- **الإحصائيات**: إجمالي الديون، الديون المتأخرة، المحصل هذا الشهر، معدل التحصيل

## نظام التوجيه التلقائي

### كيف يعمل
1. عند تسجيل الدخول، يتحقق النظام من إدارة المستخدم
2. إذا كان للإدارة لوحة تحكم خاصة، يتم التوجيه تلقائياً
3. يظهر رسالة ترحيب مخصصة للإدارة
4. يطبق نمط الألوان الخاص بالإدارة

### ملف التوجيه
- **الملف**: `assets/js/department-router.js`
- **الوظائف**: التوجيه التلقائي، تطبيق النمط، إنشاء رسائل الترحيب

## الصلاحيات والوصول

### التوجيه التلقائي
- يحدث عند تسجيل الدخول في `dashboard.html` أو `index.html`
- يعتمد على حقل `department` في بيانات المستخدم
- يحفظ سجل للتوجيه في سجل النشاط

### صلاحيات المديرين
- مديري النظام يمكنهم رؤية جميع لوحات الإدارات
- يظهر قسم "لوحات الإدارات" في اللوحة الرئيسية
- إمكانية التنقل بين إدارات مختلفة

## التهيئة والإعداد

### 1. إعداد الإدارات (مرة واحدة)
```bash
node scripts/setup_departments.js
```

### 2. تحديث المستخدمين الموجودين (مرة واحدة)
```bash
node scripts/update_users_departments.js
```

### 3. الملفات المطلوبة
- `assets/js/department-router.js` - نظام التوجيه
- `archive-dashboard.html` - لوحة إدارة الأرشيف
- `legal-dashboard.html` - لوحة الشؤون القانونية  
- `collection-dashboard.html` - لوحة إدارة التحصيل

## الميزات المتقدمة

### رسائل الترحيب
- تظهر عند التوجيه التلقائي لأول مرة
- مخصصة بألوان ورموز الإدارة
- تختفي تلقائياً بعد 5 ثوانِ

### تطبيق النمط
- كل إدارة لها لون مميز
- يطبق على العناصر الرئيسية (header, buttons, cards)
- يحديث عنوان الصفحة ليشمل اسم الإدارة

### النشاط والإحصائيات
- تحميل إحصائيات خاصة بكل إدارة
- عرض النشاط الأخير للإدارة فقط
- رؤية القضايا/الديون العاجلة حسب الإدارة

## إضافة إدارات جديدة

```html
<!-- إنشاء ملف HTML جديد مثل governance-dashboard.html -->
```


## استكشاف الأخطاء

### المستخدم لا يتم توجيهه
1. تحقق من حقل `department` في بيانات المستخدم
2. تأكد من وجود لوحة التحكم في `departmentDashboards`
3. راجع console للرسائل التشخيصية

### لوحة التحكم لا تظهر البيانات
1. تحقق من إعدادات Firestore
2. تأكد من صلاحيات المستخدم
3. راجع أسماء المجموعات في قاعدة البيانات

### الألوان لا تطبق
1. تأكد من تحميل `department-router.js`
2. تحقق من CSS variables في المتصفح
3. راجع console للأخطاء JavaScript

## الاستخدام اليومي

### للمستخدمين العاديين
- يتم التوجيه تلقائياً للوحة إدارتهم
- رؤية إحصائيات وأنشطة إدارتهم فقط
- وصول سريع لأدوات الإدارة المخصصة

### للمديرين
- إمكانية رؤية جميع لوحات الإدارات
- التنقل بين الإدارات المختلفة
- مراقبة أداء جميع الإدارات

### لمديري النظام
- وصول كامل لجميع الإدارات
- إدارة المستخدمين عبر الإدارات
- تقارير شاملة عن النظام

## ملاحظات مهمة

1. **النسخ الاحتياطي**: تأكد من عمل نسخة احتياطية قبل تشغيل scripts التحديث
2. **الاختبار**: اختبر النظام مع مستخدمين من إدارات مختلفة
3. **الصلاحيات**: راجع صلاحيات المستخدمين بعد التحديث
4. **الأداء**: راقب أداء النظام مع زيادة عدد المستخدمين

## دعم إضافي

لأي مشاكل أو استفسارات:
1. راجع console المتصفح للأخطاء
2. تحقق من logs Firebase
3. راجع ملف `activity_logs` في Firestore
4. استخدم أدوات المطور لتتبع العمليات
