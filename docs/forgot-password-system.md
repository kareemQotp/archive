# 🔐 نظام نسيت كلمة المرور - نظام الأرشيف

## 📋 الوصف
تم إضافة نظام شامل لاستعادة كلمة المرور يعتمد على Firebase Authentication مع واجهة مستخدم متطورة باللغة العربية.

## 🌊 الصفحات المضافة

### 1. **صفحة نسيت كلمة المرور** (`forgot-password.html`)
- **الوظيفة**: إرسال رابط إعادة تعيين كلمة المرور عبر البريد الإلكتروني
- **المزايا**:
  - ✅ واجهة عربية متجاوبة بألوان "أمان والبحر"
  - ✅ التحقق من صحة البريد الإلكتروني
  - ✅ مؤشرات تحميل وحالة
  - ✅ إعادة إرسال الرابط
  - ✅ معالجة أخطاء شاملة

### 2. **صفحة إعادة تعيين كلمة المرور** (`reset-password.html`)
- **الوظيفة**: تعيين كلمة مرور جديدة باستخدام الرابط المرسل
- **المزايا**:
  - ✅ مؤشر قوة كلمة المرور
  - ✅ متطلبات كلمة المرور واضحة
  - ✅ تأكيد كلمة المرور
  - ✅ التحقق من صحة الرابط
  - ✅ توجيه تلقائي بعد النجاح

## 🔧 الوظائف الأساسية

### **1. إرسال رابط إعادة التعيين**
```javascript
async function sendPasswordReset(email) {
    const actionCodeSettings = {
        url: window.location.origin + '/login.html',
        handleCodeInApp: false,
    };
    
    await auth.sendPasswordResetEmail(email, actionCodeSettings);
}
```

### **2. التحقق من قوة كلمة المرور**
```javascript
function checkPasswordStrength(password) {
    const requirements = {
        length: password.length >= 8,
        uppercase: /[A-Z]/.test(password),
        lowercase: /[a-z]/.test(password),
        number: /\d/.test(password)
    };
    // تحديث واجهة المتطلبات
}
```

### **3. تأكيد إعادة التعيين**
```javascript
async function resetPassword(code, newPassword) {
    await auth.confirmPasswordReset(code, newPassword);
    // توجيه للصفحة الرئيسية
}
```

### **للمستخدمين:**
1. **في صفحة تسجيل الدخول**: انقر على "نسيت كلمة المرور؟"
