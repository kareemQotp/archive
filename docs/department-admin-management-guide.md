# دليل إدارة المدراء حسب الإدارات - نظام الأرشيف

## المميزات الجديدة المُضافة

### 1. تحديد الإدارة عند إنشاء المدير 🏢

#### أ) قائمة الإدارات المتاحة:
- **إدارة الأرشيف** - المسؤولة عن إدارة وتنظيم الوثائق
- **إدارة الشؤون القانونية** - المسؤولة عن الجوانب القانونية
- **إدارة الحوكمة والامتثال** - المسؤولة عن الحوكمة والامتثال
- **إدارة التحصيل** - المسؤولة عن عمليات التحصيل
- **إدارة التوريق** - المسؤولة عن عمليات التوريق
- **إدارة المالية** - المسؤولة عن الشؤون المالية
- **إدارة الموارد البشرية** - المسؤولة عن شؤون الموظفين
- **إدارة تقنية المعلومات** - المسؤولة عن الأنظمة التقنية
- **الإدارة العامة** - للمهام الإدارية العامة

#### ب) بيانات إضافية:
- **المنصب**: (مدير الإدارة، نائب المدير، مساعد المدير، إلخ)
- **الإدارة**: (اختيار إجباري)

### 2. عرض محسّن لقائمة المدراء 📋

#### أ) معلومات تفصيلية:
- **البيانات الشخصية**: الاسم، البريد الإلكتروني، رقم الهاتف
- **المعلومات الوظيفية**: الإدارة، المنصب
- **حالة الحساب**: نشط / غير نشط
- **آخر دخول**: تاريخ آخر تسجيل دخول

#### ب) تخطيط محسّن:
- عمود منفصل للإدارة والمنصب
- أيقونات واضحة للحالة
- ألوان متدرجة للتمييز

### 3. نظام البحث والفلترة المتقدم 🔍

#### أ) البحث النصي:
- البحث في الأسماء
- البحث في البريد الإلكتروني
- البحث في أرقام الهواتف
- البحث في أسماء الإدارات
- البحث في المناصب

#### ب) الفلترة حسب الإدارة:
- قائمة منسدلة لاختيار إدارة محددة
- خيار "جميع الإدارات" لعرض الكل
- إمكانية الجمع بين البحث والفلترة

### 4. قاعدة البيانات المحدثة 💾

#### الحقول الجديدة:
```javascript
{
    uid: "معرف المستخدم",
    email: "البريد الإلكتروني",
    displayName: "الاسم الكامل",
    phone: "رقم الهاتف",
    department: "كود الإدارة", // جديد
    position: "المنصب",        // جديد
    role: "admin",
    isActive: true,
    permissions: {
        isAdmin: true,
        canManageSystem: true,
        // باقي الصلاحيات...
    },
    createdAt: "وقت الإنشاء",
    createdBy: "معرف المنشئ"
}
```

### 5. نظام التتبع والمراجعة 📊

#### أ) سجل العمليات (Audit Logs):
- تسجيل إنشاء المدراء مع بيانات الإدارة
- تتبع التعديلات على البيانات
- معرف المستخدم الذي قام بالعملية

#### ب) الإحصائيات:
- إجمالي المدراء
- المدراء النشطون
- المدراء غير النشطين
- عدد عمليات الدخول الأخيرة
- إحصائيات حسب الإدارة (في وحدة التحكم)

## كيفية الاستخدام

### إنشاء مدير جديد:
1. انقر على "إضافة مدير جديد"
2. املأ البيانات الأساسية (الاسم، البريد، كلمة المرور)
3. **اختر الإدارة** من القائمة المنسدلة (إجباري)
4. أدخل المنصب (اختياري، افتراضي: "مدير")
5. حدد الصلاحيات الإضافية
6. انقر "إنشاء المدير"

### البحث والفلترة:
1. **للبحث العام**: اكتب في خانة "البحث عن مدير"
2. **للفلترة حسب الإدارة**: اختر إدارة من القائمة المنسدلة
3. **للجمع بينهما**: استخدم كلاً من الفلتر والبحث معاً

### عرض المعلومات:
- **الإدارة**: تظهر في عمود منفصل بالاسم الكامل
- **المنصب**: يظهر تحت اسم الإدارة
- **الحالة**: مُلونة (أخضر للنشط، أحمر لغير النشط)

## أمثلة عملية

### مثال 1: إنشاء مدير لإدارة الأرشيف
```
الاسم: أحمد محمد علي
البريد: ahmed.ali@company.com
الإدارة: إدارة الأرشيف
المنصب: مدير الإدارة
الصلاحيات: جميع الصلاحيات مفعلة
```

### مثال 2: البحث عن مدير
```
البحث: "أحمد" -> يظهر جميع المدراء باسم أحمد
الفلتر: "إدارة الأرشيف" -> يظهر مدراء الأرشيف فقط
البحث + الفلتر: "علي" + "إدارة المالية" -> مدراء بالاسم علي في المالية
```

### مثال 3: عرض المعلومات
```

👨‍💼 المنصب: مدير الإدارة

✅ الحالة: نشط
📅 آخر دخول: 2025/01/08
```
