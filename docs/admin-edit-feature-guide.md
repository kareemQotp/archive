# دليل تعديل المدراء - نظام الأرشيف

## نظرة عامة
تم إضافة نظام تعديل شامل للمدراء يتيح تحديث جميع بيانات المدير بما في ذلك المعلومات الشخصية، الإدارة، المنصب، والصلاحيات.

## المميزات الجديدة

### 1. نافذة تعديل شاملة 📝
- **واجهة سهلة الاستخدام**: نافذة منبثقة مع جميع الحقول
- **تحميل تلقائي للبيانات**: البيانات الحالية تظهر تلقائياً
- **تصميم متجاوب**: يعمل على جميع أحجام الشاشات

### 2. الحقول القابلة للتعديل ✏️

#### أ) المعلومات الأساسية:
- **الاسم الكامل**: تعديل اسم المدير
- **رقم الهاتف**: إضافة أو تعديل رقم الهاتف
- **حالة الحساب**: تفعيل/تعطيل الحساب

#### ب) المعلومات الوظيفية:
- **الإدارة**: تغيير الإدارة المسؤول عنها
- **المنصب**: تحديث المنصب الوظيفي

#### ج) الصلاحيات:
- **إدارة النظام**: تحكم في النظام العام
- **إدارة المستخدمين**: إضافة وحذف المستخدمين
- **عرض جميع الوثائق**: الوصول لجميع الملفات
- **إدارة الوثائق**: تعديل وحذف الوثائق

### 3. إعادة تعيين كلمة المرور 🔐
- **خيار اختياري**: يمكن تفعيله عند الحاجة
- **آلية آمنة**: إرسال رابط إعادة التعيين عبر البريد الإلكتروني
- **تأكيد مزدوج**: رسائل تأكيد قبل التنفيذ

### 4. الحقول المحمية 🛡️
- **البريد الإلكتروني**: للقراءة فقط (لا يمكن تعديله)
- **معرف المستخدم**: محفوظ تلقائياً
- **تاريخ الإنشاء**: محفوظ من التعديل

## كيفية الاستخدام

### فتح نافذة التعديل:
1. انتقل إلى قائمة المدراء
2. انقر على زر "⚙️" بجانب المدير المراد تعديله
3. اختر "تعديل" من القائمة المنسدلة
4. ستفتح نافذة التعديل مع البيانات الحالية

### تعديل البيانات:
1. **البيانات الأساسية**: عدّل الاسم ورقم الهاتف حسب الحاجة
2. **حالة الحساب**: اختر "نشط" أو "غير نشط"
3. **الإدارة والمنصب**: اختر الإدارة الجديدة وحدّث المنصب
4. **الصلاحيات**: فعّل أو عطّل الصلاحيات حسب الحاجة

### إعادة تعيين كلمة المرور:
1. ضع علامة ✅ على "إعادة تعيين كلمة المرور"
2. سيتم إرسال رابط إعادة التعيين للبريد الإلكتروني
3. المدير سيستلم الرابط ويمكنه تغيير كلمة المرور

### حفظ التعديلات:
1. راجع جميع البيانات المدخلة
2. انقر "حفظ التعديلات"
3. تأكيد التحديث في الرسالة المنبثقة
4. انتظار رسالة النجاح

```
☑️ إدارة النظام        ☑️ عرض جميع الوثائق

🔑 إعادة تعيين كلمة المرور:

```

### أمثلة التحديث:

#### مثال 1: تغيير الإدارة
```
قبل: إدارة الأرشيف - مدير الإدارة
بعد: إدارة المالية - نائب المدير
```

#### مثال 2: تحديث الصلاحيات
```
قبل: جميع الصلاحيات مفعلة
بعد: إدارة النظام فقط (تم إلغاء الباقي)
```

#### مثال 3: تعطيل الحساب
```
قبل: نشط
بعد: غير نشط (لن يتمكن من تسجيل الدخول)
```

## المميزات التقنية

### الأمان:
- ✅ **التحقق من الصلاحيات**: التأكد من صلاحية المحرر
- ✅ **تسجيل العمليات**: حفظ جميع التعديلات في audit_logs
- ✅ **التحقق من البيانات**: فحص صحة البيانات قبل الحفظ
- ✅ **منع التداخل**: تعطيل الأزرار أثناء المعالجة

### إدارة الأخطاء:
- ✅ **رسائل واضحة**: أخطاء مفهومة باللغة العربية
- ✅ **التعافي التلقائي**: إعادة تفعيل الواجهة عند الفشل
- ✅ **التحقق المسبق**: فحص البيانات قبل الإرسال

### تجربة المستخدم:
- ✅ **تحميل سريع**: البيانات تظهر فوراً
- ✅ **حفظ تلقائي**: لا يحتاج إعادة كتابة
- ✅ **رسائل التأكيد**: تأكيد قبل كل عملية حساسة
- ✅ **مؤشرات التحميل**: عرض حالة المعالجة

## إدارة كلمات المرور

### الآلية الحالية:
1. **إرسال رابط إعادة التعيين**: عبر Firebase Auth
2. **البريد الإلكتروني**: يتلقى المدير رابط آمن
3. **تعيين جديد**: المدير يحدد كلمة مرور جديدة

### للمطورين - التحسين المستقبلي:
```javascript
// يمكن تطوير Cloud Function لتحديث كلمة المرور مباشرة
const updatePasswordFunction = firebase.functions().httpsCallable('updateAdminPassword');
await updatePasswordFunction({
    userId: adminId,
    newPassword: newPassword
});
```
