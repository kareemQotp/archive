# نظام إدارة المدراء - نظام الأرشيف

## نظرة عامة

تم إنشاء نظام شامل لإدارة المدراء في نظام الأرشيف، يتضمن صفحات متخصصة لإنشاء وإدارة حسابات المدراء مع صلاحيات متقدمة.

## الصفحات المُنشأة

### 1. صفحة إنشاء المدير (`create-admin.html`)

**الغرض**: إنشاء أول حساب مدير في النظام أو إضافة مدراء جدد

**المميزات**:
- تصميم عصري مع تدرجات لونية متناسقة
- نموذج آمن لإدخال بيانات المدير
- فحص قوة كلمة المرور مع مؤشر بصري
- متطلبات كلمة المرور مع فحص تفاعلي
- تكامل كامل مع Firebase Auth و Firestore
- تسجيل عمليات التدقيق (Audit Logs)

**الحقول المطلوبة**:
- الاسم الكامل
- البريد الإلكتروني  
- رقم الهاتف (اختياري)
- كلمة المرور (مع متطلبات أمان)
- تأكيد كلمة المرور

**متطلبات كلمة المرور**:
- 8 أحرف على الأقل
- حرف كبير واحد على الأقل
- حرف صغير واحد على الأقل
- رقم واحد على الأقل
- رمز خاص واحد على الأقل

### 2. صفحة إدارة المدراء (`admin-management.html`)

**الغرض**: إدارة شاملة لجميع المدراء في النظام

**المميزات**:
- قائمة جانبية متكاملة مع نظام الأدوار
- إحصائيات سريعة (إجمالي المدراء، النشطين، غير النشطين، تسجيلات الدخول الأخيرة)
- قائمة تفاعلية بجميع المدراء مع معلومات مفصلة
- بحث سريع في أسماء وبيانات المدراء
- إمكانية إضافة مدراء جدد من خلال نافذة منبثقة
- إدارة حالة المدراء (تفعيل/تعطيل)
- حذف المدراء مع تأكيدات أمان
- عرض الصلاحيات والأذونات لكل مدير

**الإحصائيات المعروضة**:
- إجمالي عدد المدراء
- المدراء النشطون
- المدراء غير النشطين  
- تسجيلات الدخول خلال الأسبوع

**العمليات المتاحة**:
- إضافة مدير جديد
- تعديل بيانات المدير
- تفعيل/تعطيل المدير
- حذف المدير
- البحث والفلترة

## التكامل مع النظام

### 1. القائمة الجانبية
تم تحديث `sidebar.js` لإضافة رابط "إدارة المدراء" للمدراء فقط:
```javascript
// إدارة المدراء - متاحة للمدراء فقط
if (userRole === 'admin' && window.hasPermission && window.hasPermission(userRole, 'manage_users')) {
    navigationHTML += `
        <li class="sidebar-nav-item">
            <a href="admin-management.html" class="sidebar-nav-link">
                <i class="fas fa-user-shield"></i>
                إدارة المدراء
            </a>
        </li>
    `;
}
```

### 2. الصفحة الرئيسية
تم إضافة رابط "إعداد حساب المدير" في الصفحة الرئيسية للمستخدمين غير المسجلين:
```html
<div class="text-center mt-3">
    <small class="text-muted">مدير النظام؟</small>
    <a href="create-admin.html" class="btn btn-link btn-sm">
        <i class="fas fa-user-shield me-1"></i>
        إعداد حساب المدير
    </a>
</div>
```

## الأمان والصلاحيات

### صفحة إنشاء المدير
- فحص قوة كلمة المرور
- التحقق من تطابق كلمات المرور
- التحقق من عدم وجود البريد الإلكتروني مسبقاً
- تسجيل جميع عمليات إنشاء المدراء في Audit Logs

### صفحة إدارة المدراء
- متاحة للمدراء فقط (`role === 'admin'`)
- التحقق من صلاحية `manage_users`
- حماية من حذف المدير لنفسه
- تأكيدات أمان قبل العمليات الحساسة
- تسجيل جميع العمليات في Audit Logs

## قاعدة البيانات

### مجموعة `users`
```javascript
{
    uid: "user_id",
    email: "admin@example.com",
    displayName: "اسم المدير",
    phone: "phone_number",
    role: "admin",
    isActive: true,
    permissions: {
        isAdmin: true,
        canManageSystem: true,
        canManageUsers: true,
        canViewAllDocuments: true,
        canManageDocuments: true
    },
    createdAt: Timestamp,
    createdBy: "creator_uid",
    lastLogin: Timestamp,
    updatedAt: Timestamp,
    updatedBy: "updater_uid"
}
```

### مجموعة `audit_logs`
```javascript
{
    action: "admin_created|admin_activated|admin_deactivated|admin_deleted",
    targetType: "user",
    targetId: "target_user_id",
    details: {
        email: "target_email",
        displayName: "target_name",
        role: "admin",
        permissions: {...}
    },
    timestamp: Timestamp,
    performedBy: "performer_uid"
}
```

## التصميم والواجهة

### الألوان والتدرجات
- اللون الأساسي: `#dc3545` (أحمر للمدير)
- اللون الثانوي: `#667eea` (أزرق)
- تدرجات: `linear-gradient(135deg, #dc3545 0%, #667eea 100%)`

### المكونات المميزة
- أيقونات مخصصة لكل مدير
- شارات حالة (نشط/غير نشط)
- شارات الصلاحيات
- مؤشر قوة كلمة المرور
- نوافذ منبثقة عصرية

### الاستجابة للشاشات
- تصميم متجاوب لجميع أحجام الشاشات
- قائمة جانبية قابلة للطي على الهواتف
- تخطيط متكيف للبطاقات والجداول

## الاستخدام

### إنشاء أول مدير
1. زيارة `create-admin.html`
2. ملء النموذج بالبيانات المطلوبة
3. التأكد من قوة كلمة المرور
4. النقر على "إنشاء حساب المدير"
5. التوجه لوحة التحكم تلقائياً

### إدارة المدراء الحاليين
1. تسجيل الدخول كمدير
2. الانتقال لـ "إدارة المدراء" من القائمة الجانبية
3. عرض الإحصائيات والقائمة
4. استخدام البحث للعثور على مدراء محددين
5. إجراء العمليات المطلوبة (إضافة، تعديل، حذف)
