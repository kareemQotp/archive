# Phase 8 Operations Runbook

الحالة: Active
التاريخ: 2026-06-01

## 1) الهدف
دليل تشغيل للإطلاق التدريجي ومراقبة الاستقرار مع خطة رجوع واضحة عند أي خلل.

## 2) قنوات المراقبة
- Activity Logs (`activity_logs`)
- الصفحة التشغيلية `movement-reports.html`
- أخطاء المتصفح/شبكة Firebase في الصفحات الحرجة

## 3) سيناريو التشغيل القياسي
1. Deploy Hosting.
2. التحقق الفوري من صفحات التشغيل.
3. Deploy Rules/Indexes.
4. إعادة اختبار مسارات البحث والWorkflow.
5. Deploy Functions (عند الحاجة).
6. اعتماد الإصدار بعد smoke checks.

## 4) مؤشرات فشل تستدعي الرجوع
- ارتفاع مفاجئ في `permission-denied`.
- تعطل مسار create/review/dispatch/receive/return.
- فشل مستمر في تحميل التقارير التشغيلية.
- ظهور أخطاء حرجة تؤثر على المستخدم النهائي.

## 5) خطة الرجوع (Rollback)
1. إعادة نشر Hosting آخر نسخة مستقرة.
2. إعادة نشر Firestore Rules آخر نسخة مستقرة.
3. إعادة نشر Firestore Indexes آخر نسخة مستقرة (إن لزم).
4. إعادة نشر Functions آخر نسخة مستقرة (إن لزم).
5. إعادة تنفيذ smoke checks الأساسية.

## 6) Post-Rollback Verification
- صفحة `file-tracking.html` تعمل بدون أخطاء حرجة.
- صفحة `client-files.html` تعمل والبحث يعرض نتائج.
- صفحة `movement-reports.html` تعرض الإحصائيات الأساسية.
- لا يوجد وصول غير مصرح للأدوار غير الإدارية.

## 7) سجل الحوادث
لكل حادثة:
- وقت البدء/الانتهاء
- التأثير
- السبب الجذري
- الإجراء العلاجي
- الإجراءات الوقائية المستقبلية
