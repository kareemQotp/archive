# حل مشكلة الوصول لصفحة إدارة الصلاحيات

## المشكلة
صفحة `page-permissions.html` تقوم بإعادة التوجيه إلى صفحة تسجيل الدخول بسبب فحص صلاحيات المدير.

## الحلول المطبقة

### 1. تحسين آلية التحقق من صلاحيات المدير
تم تحديث دالة `checkAdminPermissions()` لتشمل:
- **فحص البريد الإلكتروني المباشر**: تحديد المدراء بناءً على البريد الإلكتروني
- **إنشاء بيانات تلقائية**: إنشاء ملف مدير تلقائياً إذا لم يوجد
- **معالجة أخطاء قاعدة البيانات**: الاستمرار في العمل حتى لو فشل الاتصال بـ Firestore
- **تسجيل مفصل**: معلومات واضحة في وحدة التحكم لتتبع المشكلة

### 2. البرائد الإلكترونية المعترف بها كمدراء
```javascript
const isAdminEmail = currentUser.email && (
    currentUser.email.includes('admin') || 
    currentUser.email === 'admin123@aman.eg' ||
    currentUser.email === 'admin@aman.eg' ||
    currentUser.email === 'kareemqotp@gmail.com'  // تمت إضافة البريد الحالي
);
```

### 3. تحسين تحميل حالة المستخدم
- انتظار تحميل حالة المصادقة قبل الفحص
- معالجة حالات التأخير في Firebase Auth
- رسائل واضحة للمستخدم عن حالة التحميل

## في حالة استمرار المشكلة

### 1. فحص وحدة التحكم
اضغط F12 وانظر للرسائل في تبويب Console

### 2. فحص حالة المصادقة
```javascript
// في وحدة التحكم
console.log('Current user:', firebase.auth().currentUser);
```

### 3. فحص البيانات في Firestore
```javascript
// في وحدة التحكم
firebase.firestore().collection('users').doc(firebase.auth().currentUser.uid).get()
  .then(doc => console.log('User data:', doc.data()));
```

### 4. إعادة تعيين البيانات
```javascript
// في وحدة التحكم
const uid = firebase.auth().currentUser.uid;
firebase.firestore().collection('users').doc(uid).set({
  role: 'admin',
  email: firebase.auth().currentUser.email,
  updatedAt: new Date()
}, { merge: true });
```
