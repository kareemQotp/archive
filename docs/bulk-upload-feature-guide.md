# دليل ميزة الرفع المجمع - نظام الأرشيف

## نظرة عامة
تم إضافة ميزة الرفع المجمع (Bulk Upload) لصفحة رفع الملفات، والتي تسمح للمستخدمين برفع عدة ملفات دفعة واحدة مع خيارات مرنة لإدارة البيانات الوصفية.

## المميزات الجديدة

### 1. واجهة التبويب المحدثة
- **تبويب "رفع ملف واحد"**: للرفع التقليدي (الوضع الحالي)
- **تبويب "الرفع المجمع"**: للرفع المتقدم لعدة ملفات

### 2. منطقة الإسقاط المحسنة
- منطقة إسقاط مخصصة للملفات المتعددة
- دعم السحب والإفلات للمجموعات الكبيرة
- رسائل توضيحية واضحة باللغة العربية

### 3. أوضاع البيانات الوصفية

#### أ) البيانات الموحدة
- **الاستخدام**: عندما تريد تطبيق نفس البيانات على جميع الملفات
- **المميزات**:
  - عنوان أساسي موحد (يُضاف إليه اسم كل ملف)
  - وصف عام لجميع الملفات
  - فئة موحدة
  - علامات مشتركة
- **مثال**: رفع مجموعة تقارير شهرية أو عقود من نفس النوع

#### ب) البيانات المنفصلة
- **الاستخدام**: عندما تريد بيانات مختلفة لكل ملف
- **المميزات**:
  - إمكانية تحرير بيانات كل ملف بشكل منفصل
  - زر "تحرير البيانات" لكل ملف
  - واجهة قابلة للطي والإظهار
- **مثال**: رفع ملفات متنوعة (عقود، تقارير، فواتير)

### 4. نظام التقدم المتقدم

#### أ) التقدم الإجمالي
- شريط تقدم عام يُظهر نسبة إكمال العملية الكاملة
- نسبة مئوية دقيقة للتقدم

#### ب) التقدم الفردي
- شريط تقدم منفصل لكل ملف
- حالة كل ملف (جاري الرفع، مكتمل، فشل)
- رسائل حالة واضحة

### 5. إدارة الأخطاء المحسنة
- تتبع منفصل لنجاح/فشل كل ملف
- رسائل خطأ مفصلة لكل ملف فاشل
- إمكانية المتابعة حتى لو فشل بعض الملفات
- ملخص نهائي شامل للعملية

## كيفية الاستخدام

### للرفع بالبيانات الموحدة:
1. انتقل إلى تبويب "الرفع المجمع"
2. اسحب الملفات أو انقر للاختيار
3. اختر "بيانات موحدة لجميع الملفات"
4. املأ البيانات الأساسية (العنوان، الوصف، الفئة، العلامات)
5. انقر "رفع جميع الملفات"

### للرفع بالبيانات المنفصلة:
1. انتقل إلى تبويب "الرفع المجمع"
2. اسحب الملفات أو انقر للاختيار
3. اختر "بيانات منفصلة لكل ملف"
4. انقر "تحرير البيانات" لكل ملف تريد تخصيص بياناته
5. املأ البيانات المطلوبة لكل ملف
6. انقر "رفع جميع الملفات"

## الضوابط والقيود

### أنواع الملفات المدعومة
- مستندات: PDF, DOC, DOCX, XLS, XLSX
- صور: PNG, JPG, JPEG

### حد الحجم
- حد أقصى: 10 ميجابايت لكل ملف
- لا يوجد حد أقصى لعدد الملفات (محدود بالذاكرة)

### الحقول المطلوبة
- **للبيانات الموحدة**: فئة الوثائق (مطلوبة)
- **للبيانات المنفصلة**: فئة كل ملف (مطلوبة)

## المميزات التقنية

### الأداء
- رفع متسلسل (واحد تلو الآخر) لتجنب مشاكل الشبكة
- تتبع دقيق للتقدم باستخدام Firebase Storage
- إدارة ذكية للذاكرة

### الأمان
- تحقق من نوع الملف قبل الرفع
- تحقق من حجم الملف
- مصادقة المستخدم مطلوبة
- تسجيل معرف المستخدم مع كل ملف

### قاعدة البيانات
- حفظ بيانات وصفية شاملة لكل ملف
- تسجيل طريقة الرفع (bulk/single)
- timestamp دقيق لوقت الرفع
- ربط بمعرف المستخدم

## واجهة المستخدم

### التصميم العربي
- دعم كامل للكتابة من اليمين لليسار (RTL)
- خط Cairo العربي
- رسائل واضحة باللغة العربية
- أيقونات متناسقة مع نظام الألوان

### الاستجابة
- تصميم متجاوب لجميع أحجام الشاشات
- واجهة محسنة للهواتف الذكية
- أزرار وعناصر بحجم مناسب للمس

## رسائل النجاح والخطأ

### رسائل النجاح
- "تم رفع جميع الملفات بنجاح! (X ملف)"
- "تم رفع X من Y ملف بنجاح"

### رسائل الخطأ
- تفاصيل الملفات الفاشلة
- أسباب الفشل لكل ملف
- إرشادات للإصلاح

## التحسينات المستقبلية

### مقترحات للنسخ القادمة
1. **رفع متوازي**: رفع عدة ملفات في نفس الوقت
2. **استكمال الرفع**: إمكانية إعادة رفع الملفات الفاشلة فقط
3. **معاينة الملفات**: عرض محتوى الملفات قبل الرفع
4. **قوالب البيانات**: حفظ قوالب للبيانات الوصفية المتكررة
5. **ضغط الملفات**: ضغط تلقائي للملفات الكبيرة
6. **جدولة الرفع**: رفع الملفات في أوقات محددة

## ملاحظات للمطورين

### الملفات المُحدثة
- `upload.html`: إضافة واجهة الرفع المجمع

- دوال إدارة التقدم والبيانات الوصفية

- متوافق مع نظام المصادقة الحالي
- متكامل مع Firestore و Firebase Storage
